06 FAQ SOFTWARE

Dudas típicas antes de pedir una herramienta.

¿Me entregas el código fuente?

Sí. Al cerrar el proyecto te entrego el código, el ejecutable o instalador y una guía de uso. El proyecto es tuyo.

¿Te encargas de publicar la web o la app?

Puedo dejarla publicada (por ejemplo en GitHub Pages o en tu hosting) o prepararte el APK/instalador para que lo distribuyas tú.

¿Qué pasa si encuentro un fallo después de la entrega?

Cada proyecto incluye un periodo de soporte para corregir errores. Mejoras o funciones nuevas se cotizan aparte.

¿Puedes continuar un proyecto que empezó otra persona?

Sí, si el stack lo permite. Primero reviso el código y te digo con honestidad si conviene continuarlo o rehacer partes.
