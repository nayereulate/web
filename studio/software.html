Preguntas frecuentes

Sobre desarrollo

¿Me entregas el código fuente?

Sí. Al cerrar el proyecto recibes el código, el ejecutable o instalador y una guía de uso. El proyecto es tuyo.

¿Te encargas de publicar la web o la app?

Puedo dejarla publicada en tu hosting o en GitHub Pages, o prepararte el APK o instalador para que lo distribuyas.

¿Qué pasa si aparece un fallo después de la entrega?

Cada proyecto incluye un periodo de soporte para corregir errores. Las funciones nuevas se cotizan aparte.

¿Puedes continuar un proyecto que empezó otra persona?

Sí, si el stack lo permite. Primero reviso el código y te digo con honestidad si conviene continuarlo o rehacer partes.

Cuéntame el problema que quieres resolver

El cotizador te da una estimación de plan y plazo en un par de minutos, y me llega todo lo necesario para preparar tu propuesta.
